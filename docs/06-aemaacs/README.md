# AEM as a Cloud Service

## Mission

Help learners understand the operational and architectural differences between AEM on-premises concerns and cloud-native service patterns.

## Learning objectives

By the time this chapter is published, readers should be able to:

- distinguish cloud service operating models from traditional platform assumptions
- interpret the impact of managed service boundaries on delivery, support, and governance
- align cloud adoption decisions with reliability, security, and product ownership expectations

## Topics planned

- cloud service architecture and operational model
- managed platform responsibilities and team boundaries
- release, scaling, and support implications
- enterprise patterns for cloud-first AEM delivery

## Estimated release

Planned for the next major release stream focused on cloud and enterprise practice.
